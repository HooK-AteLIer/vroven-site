## Что должно заработать

Вместо сетки 4×2 плиток стилей — веер фото-карточек, как в присланном компоненте card-fan-carousel: выбранный стиль в центре, крупно и прямо; соседние разворачиваются веером с поворотом до ±21°, уменьшением и смещением вниз (позиции слотов ниже). Видно 7 карточек из 8, стрелки «влево/вправо» и точки под веером листают стили по кругу; клик по боковой карточке делает её центральной. Центральная карточка = выбранный стиль: при смене центра чертёж перерисовывается в этом стиле, подпись и описание стиля обновляются, `#style=` в адресе тоже. Под центральной карточкой — название стиля; чипы цветов работают как раньше и меняют фото центральной карточки.

Наведение мышью: карточка под курсором поднимается (−2,5rem) и увеличивается ×1,08, соседи раздвигаются в стороны и слегка доворачиваются, с упругим затуханием. При первом появлении карточки вылетают снизу из центра по очереди (задержка 0,06 c на слот). При листании новая карточка влетает с края, уходящая улетает за другой край.

Позиции 7 слотов (rot°, scale, x rem, y rem, z): (−21, .7756, −30, 7.3, 1), (−14, .8498, −22, 4.0, 2), (−7, .9346, −11, 1.3, 3), (0, 1, 0, 0, 10), (7, .9346, 11, 1.3, 3), (14, .8498, 22, 4.0, 2), (21, .7756, 30, 7.3, 1). x умножается на коэффициент ширины экрана: <480 → .28, <640 → .38, <768 → .5, <1024 → .75, иначе 1; y — на коэффициент высоты (если высота веера не помещается в 70% окна).

## Из брифа, дословно

> «сделай этот промт где выбор стилей кухни» — React-компонент card-fan-carousel (GSAP, shadcn, Tailwind)

## Решение по стеку

Сайт статичный, без React, Tailwind и сборки (ADR 0001) — компонент не вставляется как есть. Его поведение переносится на чистый JS в `kitchen-fan.js` (классический скрипт, `window.VROVEN.kitchenFan`), анимации — Web Animations API / CSS transitions с упругой кривой (CSS `linear()`), без GSAP и без CDN. Чистые расчёты (позиции слотов, коэффициенты, карта видимых карточек) — отдельной функцией, экспортируемой для Node.

## Критерии приёмки

- [ ] `tests/kitchen-fan.test.js`: позиции 7 слотов, коэффициенты ширины, карта видимых карточек при 8 стилях и центре 0 и 7 (по кругу) — сначала красные
- [ ] Веер показывает фото текущего цвета у центральной карточки и основного цвета у остальных (как сейчас в плитках)
- [ ] Стрелки, точки, клик по боковой карточке и клавиатура (←/→ при фокусе на веере, Enter/Space на карточке) меняют выбранный стиль; чертёж и `#style=` обновляются; `#style=loft` при загрузке ставит лофт в центр
- [ ] Наведение поднимает карточку и раздвигает соседей; на тач-устройствах наведения нет, тап выбирает
- [ ] prefers-reduced-motion: без вылета и пружин, карточки сразу на местах
- [ ] На 360 px веер помещается без горизонтального скролла; на 1440 px не наезжает на чертёж и форму
- [ ] Двойной клик по стрелке во время анимации не ломает раскладку (блокировка, как в оригинале)
- [ ] `node --test` зелёный; консоль без ошибок
