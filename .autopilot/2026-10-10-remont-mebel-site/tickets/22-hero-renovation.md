## Что должно заработать

Заказчик хочет, чтобы главный экран сначала показывал черновые стены, а при прокрутке вниз шёл ремонт: сначала чистовая отделка, потом появляется мебель. Механика скраба (видео по прокрутке) уже есть в `hero-scrub.js` — меняется ролик и тайминги.

Сырьё (координатор сгенерировал, статичная камера, 16:9):
- `media-raw/hero2/rough.png` — бетонная коробка, провода, зелёная лазерная линия уровня
- `media-raw/hero2/finish.png` — чистовая: штукатурка, дубовый пол, латунные светильники, пустая стена
- `media-raw/hero2/final.png` — готовая кухня (последний кадр прежнего ролика)
- `media-raw/hero2/seg1.mp4` — переход черновая → чистовая (6 с)
- `media-raw/hero2/seg2.mp4` — переход чистовая → мебель (6 с)

1. Склеить seg1 + seg2 в один ролик ≈12 с (если на стыке скачок кадра — короткий кроссфейд 0,2–0,3 с через `xfade`), привести к 1920×1080 (или ширине прежнего ролика 1912×1080, без искажения пропорций), 24 fps, без звука. Перекодировать по рецепту из `site/README.md` (частые ключевые кадры `-g 8 -keyint_min 8`, `+faststart`); целевой размер файла — не больше ~8 МБ (если выходит больше, поднять CRF до 20–22). Сохранить склейку-сырьё как `media-raw/hero2/hero-raw-v2.mp4`.
2. Постеры: `hero-start.jpg` — первый кадр (черновые стены), `hero-final.jpg`, `hero-final-sm.jpg`, `og-image.jpg` — последний кадр (кухня), по рецепту README. Статичный герой (мобильные, file://, reduced-motion) должен показывать итог (кухню) — как сейчас.
3. `VIDEO_BYTES` в `hero-scrub.js` = размер нового файла.
4. Тайминги полос текста героя (`data-band` в `index.html`) подогнать под фазы ролика, проверив кадры: бренд «ВРОВЕНЬ» — на черновых стенах в начале; «01 · ремонт / Сначала выравниваем стены» — пока идёт отделка (≈ первая половина); «02 · мебель / Потом делаем мебель под эти стены» — пока появляется мебель (≈ вторая половина); финальный блок — на готовой кухне. Тексты не менять, если подходят по смыслу.
5. Читаемость подписей поверх нового видео (тёмная гамма, скрим под полосами уже есть) — проверить на всех фазах, в т.ч. на светлом кадре чистовой отделки.
6. `site/README.md`: рецепт ролика переписать на новое сырьё (`media-raw/hero2/…`, склейка + перекодирование + постеры).

## Из брифа, дословно

> «попробуй сделать главный экран изначально как будто черновые стены, при промотке вниз преобразуется ремонт, сначала чистовая потом появляется мебель»

## Критерии приёмки

- [ ] При загрузке главной на десктопе видны черновые бетонные стены; при прокрутке — отделка, затем появление мебели; прокрутка вверх отматывает назад, без рывков (кадры при 0/20/40/60/80/100 % героя — скриншоты в отчёте)
- [ ] Подписи героя совпадают по смыслу с фазами и читаются на всех фазах
- [ ] Мобильный/статичный герой показывает готовую кухню; `og-image.jpg` — кухня
- [ ] Размер ролика ≤ ~8 МБ, `VIDEO_BYTES` совпадает с размером файла; консоль без ошибок; `node --test` зелёный
